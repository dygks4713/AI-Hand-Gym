# AI 손가락 체조 게임

어르신들의 손가락 운동과 소근육 활동을 돕기 위해 개발한 AI 기반 손동작 인식 체조 게임입니다.

웹캠과 MediaPipe를 활용하여 사용자의 손동작을 실시간으로 인식하고, 화면에 제시되는 동작을 따라 하며 손가락 체조를 진행할 수 있습니다.

주먹, 손바닥, 브이 총 3가지 동작을 활용하며, 양손 또는 한 손 운동 방식을 선택할 수 있습니다. 무작위 동작 출제와 점수 시스템을 통해 어르신들이 반복적인 손가락 운동에 재미있고 능동적으로 참여할 수 있도록 구성했습니다.

## 1. 개발 환경

| 항목 | 내용 |
|---|---|
| 운영체제 | Windows 10 / Windows 11 |
| 개발 언어 | Python 3.10 (64비트) |
| 게임 화면 | Pygame 2.6.1 |
| 영상 처리 | OpenCV 4.10.0.84 |
| 손동작 인식 | MediaPipe 0.10.14 |
| 데이터 처리 | NumPy 1.26.4 |
| 입력 장치 | PC 웹캠 |
| 이모티콘 폰트 | Segoe UI Emoji |

## 2. 주요 기능

### 2.1 운동 방식 선택

게임 시작 화면에서 원하는 운동 방식을 선택할 수 있습니다.
<img width="1640" height="1032" alt="image" src="https://github.com/user-attachments/assets/4659535b-d9a2-42f6-8aa5-060f4ad3355e" />
- **양손 운동:** 왼손과 오른손이 모두 목표 동작을 수행해야 성공합니다.
- **왼손 운동:** 왼손만 목표 동작을 수행하면 성공합니다.
- **오른손 운동:** 오른손만 목표 동작을 수행하면 성공합니다.

MediaPipe Hands의 손 인식 및 handedness 정보를 활용하여 왼손과 오른손을 구분합니다.

### 2.2 손동작 인식

총 3가지 손동작을 인식합니다.

| 동작 | 이모티콘 | 설명 |
|---|---|---|
| 주먹 | ✊ | 손가락을 모두 오므려 주먹을 쥡니다. |
| 손바닥 | ✋ | 손가락을 활짝 펴서 손바닥을 보여줍니다. |
| 브이 | ✌️ | 검지와 중지를 펴고 나머지 손가락은 접습니다. |
<img width="298" height="272" alt="image" src="https://github.com/user-attachments/assets/68a7b81e-a0b9-492d-b9a5-5562e7e23fec" />

MediaPipe가 검출한 손의 랜드마크 정보를 바탕으로 손가락의 펴짐과 접힘 상태를 분석하여 동작을 분류합니다.

### 2.3 무작위 동작 출제

- 매 라운드마다 4가지 손동작 중 하나를 무작위로 제시합니다.
- 직전 라운드에서 출제된 동작은 다음 라운드에서 제외합니다.
- 직전 동작을 제외한 나머지 3가지 동작 중 하나가 무작위로 선택됩니다.
- 이전 라운드와 동일한 동작이 연속으로 출제되는 것을 방지합니다.

### 2.4 실시간 동작 판정

- 웹캠을 통해 사용자의 손을 실시간으로 인식합니다.
- 선택한 운동 방식에 따라 왼손, 오른손 또는 양손의 동작을 확인합니다.
- 화면에 표시된 목표 동작과 실제 손동작을 비교합니다.
- 목표 동작을 약 0.8초 동안 유지하면 성공으로 판정합니다.
- 성공하면 10점을 획득하고 다음 라운드로 넘어갑니다.

### 2.5 화면 및 사용자 인터페이스

- 목표 손동작과 함께 이모티콘 및 동작 안내 문구를 표시합니다.
- 이모티콘 전용 폰트를 적용하여 손동작 표시를 지원합니다.
- 동작 안내 문구는 화면 영역에 맞춰 자동 줄바꿈됩니다.
- 왼손과 오른손의 인식 상태를 구분하여 표시합니다.
- 점수, 라운드, 진행 시간 등 게임 정보를 화면에 표시합니다.

## 3. 게임 진행 방식

1. 프로그램 실행 후 양손, 왼손, 오른손 중 운동 방식을 선택합니다.
2. 게임 시작 버튼을 누르면 5초 카운트다운이 진행됩니다.
3. 카운트다운이 끝나면 수행해야 할 손동작이 무작위로 표시됩니다.
4. 화면에 표시된 목표 동작을 카메라 앞에서 수행합니다.
5. 목표 동작을 약 0.8초 동안 유지하면 성공으로 판정됩니다.
6. 성공 메시지와 함께 10점을 획득합니다.
7. 성공 안내가 1.5초간 표시된 후 다음 라운드 전 5초 카운트다운이 진행됩니다.
8. 다음 라운드에서는 직전 라운드와 다른 손동작이 제시됩니다.
9. 위 과정을 총 10라운드 반복합니다.
10. 모든 라운드가 완료되면 최종 점수와 총 소요 시간이 표시됩니다.

## 4. 점수 및 게임 설정

| 항목 | 설정 |
|---|---|
| 전체 라운드 | 10라운드 |
| 라운드별 점수 | 10점 |
| 최고 점수 | 100점 |
| 목표 동작 유지 시간 | 약 0.8초 |
| 시작 카운트다운 | 5초 |
| 다음 라운드 카운트다운 | 5초 |
| 성공 메시지 표시 시간 | 1.5초 |
| 게임 시간 제한 | 없음 |

※ 카운트다운 및 성공 안내 시간도 전체 게임 소요 시간에 포함됩니다.

## 5. 화면 구성

- **점수 영역:** 현재 점수와 라운드 진행 상황 표시
- **목표 동작 영역:** 수행해야 할 손동작, 이모티콘 및 안내 문구 표시
- **카메라 영역:** 웹캠 영상 및 실시간 손 인식 결과 표시
- **손 상태 영역:** 왼손과 오른손의 인식 상태 표시
- **진행 시간 영역:** 게임 진행 시간 표시
- **성공 안내 영역:** 동작 성공 및 점수 획득 메시지 표시

사용자가 화면의 정보를 쉽게 확인할 수 있도록 큰 글씨와 명확한 색상으로 구성하며, 동작 안내 문구는 화면 영역에 맞춰 자동 줄바꿈되도록 설계합니다.

## 6. 설치 방법

프로젝트 폴더에서 PowerShell을 실행합니다.

### 6.1 가상환경 생성

```powershell
py -3.10 -m venv .venv
```

### 6.2 가상환경 활성화

```powershell
.\.venv\Scripts\Activate.ps1
```

PowerShell 실행 정책으로 활성화가 제한되는 경우 다음 명령어를 사용할 수 있습니다.

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 6.3 라이브러리 설치

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## 7. 실행 방법

가상환경을 활성화한 상태에서 다음 명령어를 실행합니다.

```powershell
python main.py
```

웹캠이 정상적으로 연결되어 있어야 손동작 인식 기능을 사용할 수 있습니다.

## 8. 조작 방법

| 키보드 | 기능 |
|---|---|
| `1` | 양손 운동 모드 선택 |
| `2` | 왼손 운동 모드 선택 |
| `3` | 오른손 운동 모드 선택 |
| `SPACE` | 선택한 모드로 게임 시작 |
| `R` | 게임 완료 후 모드 선택 화면으로 이동 |
| `ESC` | 프로그램 종료 |

마우스로도 운동 모드 카드와 게임 시작 버튼을 선택할 수 있습니다.

## 9. 인식 관련 참고사항

- MediaPipe Hands의 손 랜드마크 정보를 이용해 손가락의 상태와 손동작을 판별합니다.
- handedness 정보를 활용하여 왼손과 오른손을 구분합니다.
- 손동작 분류는 손가락 관절의 상대적인 위치와 거리를 기준으로 수행합니다.
- 브이 동작은 검지와 중지가 펴지고 약지와 새끼손가락이 접힌 상태를 기준으로 판별합니다.
- 손의 방향이나 카메라 각도, 손가락 가림 정도에 따라 인식률이 달라질 수 있습니다.
- 조명이 어둡거나 손이 카메라에서 너무 멀리 떨어져 있으면 인식이 불안정할 수 있습니다.
- 원활한 이용을 위해 손이 카메라 화면 안에 충분히 보이도록 유지하는 것이 좋습니다.

## 10. 프로젝트 목적

본 프로그램은 어르신들이 손가락 체조에 보다 쉽고 재미있게 참여할 수 있도록 개발한 웹캠 기반 손동작 인식 게임입니다.

주먹, 손바닥, 브이 등 간단한 손동작을 직접 따라 하는 과정을 통해 손가락을 반복적으로 움직이고, 소근육 활동과 눈과 손의 협응을 자극할 수 있도록 구성했습니다.

또한 별도의 키보드 조작 없이 웹캠 앞에서 손동작을 수행하는 방식으로 디지털 기기와 AI 손동작 인식 기술을 자연스럽게 경험할 수 있도록 했습니다.

양손 및 한 손 운동 모드, 무작위 동작 출제, 성공 메시지와 점수 시스템을 적용하여 어르신들이 자신의 수행 결과를 확인하고 지속적으로 참여할 수 있도록 하는 데 목적이 있습니다.

※ 본 프로그램은 인지 및 신체 활동을 위한 보조적인 체조 프로그램이며, 의학적 치료나 재활 효과를 보장하지 않습니다.
